Subjects, platforms, resume tips, and the full placement process — all in one place.

Core Subjects
🔷
DSA
Arrays, Linked Lists, Trees, Graphs, Sorting, DP, Recursion, Hashing, Heaps, Tries
💾
Operating Systems
Processes, Threads, Scheduling, Memory Management, Deadlock, File Systems, Paging
🗄️
DBMS
SQL, Normalisation, ACID, ER Diagrams, Indexing, Transactions, Joins, Keys
🌐
Computer Networks
OSI Model, TCP/IP, HTTP/HTTPS, DNS, Routing, Subnetting, Firewalls, Sockets
🧩
OOPs Concepts
Encapsulation, Abstraction, Inheritance, Polymorphism, Interfaces, Design Patterns
🧮
System Design
HLD, LLD, Load Balancers, Caching, Databases, Microservices, API Design, Scalability
Programming Languages
C++ — Best for DSA and competitive programming Java — Popular in placements, strong OOP Python — Clean syntax, good for interviews JavaScript — Needed for web dev roles
💡 Tip: Learn one language well first. For DSA interviews, C++ or Java is best. For web dev roles, also learn JavaScript.
Coding Platforms to Use
🔥 LeetCode
Best for interview prep. Solve company-tagged questions. Aim for 100+ medium problems.
✅ HackerRank
Good for beginners. Get certifications in Python, SQL, Java. Used in many company tests.
💻 CodeStudio
Topic-wise DSA sheets. Company-specific material. Very helpful for structured preparation.
⚔️ Codeforces
Competitive programming contests. Improves your speed and pressure handling.
📘 GeeksForGeeks
Theory + practice. Great for Core CS concepts like OS, DBMS, CN.
🎯 InterviewBit
Structured prep path, timed mocks. Good for final stage interview practice.

🐙 GitHub Tips
Placement Process — Step by Step
01

Aptitude Round

Quant, logical reasoning, verbal ability. Time-bound. Practice IndiaBix and R.S. Aggarwal daily.

02

Coding Round

2-3 DSA problems in 60-90 minutes. Know arrays, strings, DP, graphs. Write clean code.

03

Technical Interview

DSA questions, Core CS theory, and project discussion. Be honest about what you know.

04

HR Interview

Strengths, weaknesses, why this company, salary. Use STAR format. Stay calm.
