# SkillSync — Placement Preparation Platform

**A structured platform to help students organize their placement preparation, assess their skills, and track their learning progress.**

🔗 **Live Demo:** [Explore SkillSync](https://skillsync-okm2.onrender.com)  
💻 **GitHub Repository:** [View Source Code](https://github.com/prernagoswami05/SkillSync)

---

## 📌 Overview

SkillSync is a web-based placement preparation platform designed to make the preparation process more structured, accessible, and organized.

Students often struggle to manage their placement preparation because learning resources, assessments, and preparation plans are scattered across different platforms. SkillSync brings essential preparation modules together in a single interface, allowing users to navigate learning sections, attempt assessments, review results, and follow a more organized preparation process.

The project focuses on creating an interactive user experience with a clean interface, structured navigation, and browser-based data storage.

## 🎯 Problem Statement

Placement preparation requires consistent practice, skill development, and a clear learning direction. Without an organized system, students may find it difficult to track their progress and identify areas that need improvement.

SkillSync aims to address this challenge by providing a centralized interface for placement preparation and skill assessment.

## ✨ Key Features

- **User Login Interface** — Provides an entry point to the placement preparation platform.
- **Interactive Dashboard** — Offers a central interface for navigating the application's sections.
- **Skill-Based Preparation** — Organizes skill-related preparation content.
- **Quiz and Assessment Module** — Allows users to practice through assessments.
- **Performance Results** — Displays assessment results to help users review their performance.
- **Learning Roadmap** — Provides a structured approach to preparation.
- **Responsive Interface** — Uses modern styling and layout techniques to support different screen sizes.
- **Browser-Based Data Storage** — Uses LocalStorage to retain supported user information and assessment data in the browser.

## ⚙️ How It Works

1. Open SkillSync through the live demo.
2. Enter the application through its login interface.
3. Navigate through the dashboard and available preparation sections.
4. Explore skill-related content and attempt available assessments.
5. Review the displayed results to understand performance.
6. Use the available roadmap and preparation sections to organize further learning.

*The exact workflow depends on the functionality implemented in the current version.*

## 🚀 Getting Started

Follow these steps to run SkillSync locally.

**1. Clone the repository**

```bash
git clone https://github.com/prernagoswami05/SkillSync.git
```

**2. Navigate to the project directory**


## 💾 Data Storage

SkillSync uses the browser's LocalStorage for supported client-side data.

- Data is stored locally in the browser.
- Stored data is associated with the browser and origin being used.
- Clearing browser storage or using another browser may affect access to previously stored data.

The current project is a frontend application and does not use a connected backend database.

## 🔒 Current Scope and Limitations

- The application is implemented as a standalone frontend.
- User and assessment data are stored on the client side where implemented.
- There is no connected backend database in the current version.
- LocalStorage does not provide secure, centralized, cross-device data synchronization.
- The current login interface should not be considered production-grade authentication.
